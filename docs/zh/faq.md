# 常见问题

## MICOS-2024 是 workflow engine 吗

不是。更准确地说，它是一个围绕宏基因组工具栈构建的平台外壳，同时包含：

- 稳定 Python CLI，
- `steps/` 下的工作流资产，
- `deploy/` 和 `containers/` 下的环境资产。

## `scripts/` 里的所有脚本都属于稳定公共接口吗

不是。很多脚本是专家扩展面或探索性能力。真正稳定的命令面，请看 CLI 参考页。

## 新项目应该优先用包装脚本还是 Python CLI

优先用 Python CLI。包装脚本适合兼容旧工作流，但不应该成为新的事实标准。

## 为什么配置模板看起来比 CLI 大很多

因为模板反映的是更大的平台 ambition，而当前稳定 CLI 只覆盖其中一部分主链路。

## Docker Compose 文件能一键跑完整流程吗

更准确地说，它是环境示例和就绪脚手架，而不是对“全流程全自动”的简单承诺。

## 评审者应该从哪里开始看

建议顺序是：

1. 首页，
2. 学院 / 流程基础，
3. 架构 / 系统总览，
4. 参考 / CLI 参考。
