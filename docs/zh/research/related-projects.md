# 相关开源项目

MICOS-2024 位于一批工作流型微生物组项目之间。

## 对照表

| 项目 | 强项 | 与 MICOS-2024 的差异 |
| --- | --- | --- |
| bioBakery workflows | 微生物组工作流生态成熟 | 工作流谱系更完整，MICOS 更偏 CLI 编排整合 |
| nf-core/taxprofiler | 标准化流水线治理成熟 | 社区治理模型更完善，范围和哲学不同 |
| Sunbeam | 实用型宏基因组流程封装 | 更偏流程工程，文档呈现方式不同 |

## MICOS-2024 的定位

该项目来自 2024 MICOS 竞赛语境，同时包含 Python CLI 编排、WDL 工作流资产、容器环境定义和专家脚本扩展面。大多数同类项目更偏使用手册，本项目在文档中额外增加了架构说明和研究谱系。
