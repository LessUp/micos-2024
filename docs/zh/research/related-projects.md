# 相关开源项目探究

MICOS-2024 并不孤立，它位于一批工作流型微生物组项目之间。本页的目的不是“比高下”，而是解释它的定位。

## 对照表

| 项目 | 强项 | 与 MICOS-2024 的差异 |
| --- | --- | --- |
| bioBakery workflows | 微生物组工作流生态成熟 | 工作流谱系更强，本站则更强调整合平台与展示姿态 |
| nf-core/taxprofiler | 标准化流水线治理成熟 | 社区治理模型更完善，但项目哲学和范围不同 |
| Sunbeam | 实用型宏基因组流程封装 | 更偏流程工程，文档呈现与仓库叙事不同 |

## MICOS-2024 的差异化价值

### 1. 竞赛语境驱动

该项目明确来自 2024 MICOS 竞赛语境，因此天然带有更强的“平台展示”倾向。

### 2. 混合执行面

仓库同时拥有：

- Python CLI 编排，
- 工作流资产，
- 容器环境示例，
- 专家脚本扩展面。

如果没有好文档，这会显得杂乱；如果说明清楚，这会成为宽广而有野心的信号。

### 3. 白皮书式导读

大多数同类项目更偏使用手册。这个文档站则故意增加架构说明、研究谱系和演进思考，让项目不仅“能跑”，还“能被高质量地理解”。
