# API Reference

## CLI Commands

### full-run

Run complete analysis pipeline.

```bash
python -m micos.cli full-run [OPTIONS]
```

**Options:**

| Option | Description |
|--------|-------------|
| `--input-dir` | Input directory with FASTQ files |
| `--results-dir` | Output directory |
| `--threads` | Number of threads |
| `--kneaddata-db` | KneadData database path |
| `--kraken2-db` | Kraken2 database path |

### run

Run individual analysis module.

```bash
python -m micos.cli run [MODULE] [OPTIONS]
```

**Modules:** `quality-control`, `taxonomic-profiling`, `functional-annotation`, `diversity-analysis`
