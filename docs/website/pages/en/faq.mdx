# Frequently Asked Questions

## Installation

**Q: Which Python version is required?**

A: Python 3.9 or higher is required.

**Q: Can I use conda?**

A: Yes, use the provided `environment.yml` file.

## Usage

**Q: How to handle large datasets?**

A: Increase threads and memory in config. Use SSD storage.

**Q: Which databases are required?**

A: Depends on your analysis. Minimum: Kraken2 database.
