# Troubleshooting

## Common Issues

### Database not found

```
Error: Kraken2 database not found
```

**Solution:** Set correct path in config or use `--kraken2-db` option.

### Memory error

```
Error: Out of memory
```

**Solution:** Reduce threads or increase available memory.

### Slow performance

**Solutions:**
- Use SSD storage
- Increase thread count
- Check I/O bottlenecks
